# HED-3D

HED-3D estimates one normalized relative-depth value per engine oil fill-port ROI from a single RGB image. YOLO11m proposes the region, hierarchical ellipse localization defines the thin ring, and a MobileNetV3-Large student with deterministic and evidential heads produces a fused scalar through SoftGate.

| Directory | Contents |
| --- | --- |
| `hed3d/` | ROI inference, pseudo-label preparation, student training, evaluation, and plotting |
| `weights/` | DualKD inference weights and checkpoint provenance |
| `examples/` | Synthetic ROI inputs and a label manifest for the runnable example |
| `paper/` | Reported Table 10 summary, Figure 11 plot values, and the corresponding plot |
| `docs/` | Equations, evaluation protocol, and the scope of the public package |
| `configs/` | YOLO training and dataset templates |

## Setup

Use Python 3.10 or newer. Set up a virtual environment and install device-compatible PyTorch and torchvision before installing the remaining dependencies. See the [PyTorch installation guide](https://pytorch.org/get-started/locally/).

```bash
python -m venv .venv
# Activate the environment for your shell.
python -m pip install -r requirements.txt
```

Run the commands below from the repository root.

The public example was checked on Windows with Python 3.10, PyTorch 2.13.0 CPU, and torchvision 0.28.0 CPU.

## Run the uncertainty evaluation

The example uses ten synthetic ROI images and illustrative targets. It exercises the bundled checkpoint and the same scoring and metric code used for the public evaluation workflow.

```bash
python -m hed3d.score_student examples/demo_manifest.csv --root examples --out runs/demo/predictions.csv --expected-count 10
python -m hed3d.reliability runs/demo/predictions.csv --out runs/demo/reliability --expected-count 10
python -m hed3d.plot_risk runs/demo/reliability/risk_coverage.csv --out runs/demo/risk_coverage --title "Synthetic example"
```

The first command exports the fused prediction, both depth-head estimates, NIG parameters, SoftGate score and weight, theoretical predictive standard deviation, and head disagreement. The second command writes depth errors, high-error labels, AUROC, average precision, Pearson correlations, and two risk–coverage series. Each series ranks the same fused-prediction errors. The third command saves the figure as PNG and PDF.

The manuscript's 302-image evaluation requires its corresponding private ROI images and labels, or the original per-image prediction records. Use the same commands with the held-out manifest and `--expected-count 302`. See [the protocol and CSV schema](docs/reliability.md). The synthetic example is for execution checks.

To redraw the published Figure 11 from its reported aggregate values:

```bash
python -m hed3d.plot_risk paper/figure11_risk_coverage.csv --out runs/paper/Figure11
```

## Run inference or prepare labels

For a pre-cropped ROI, run the model with the bundled student weights:

```bash
python -m hed3d.run examples/rois/demo_01.png --roi-input --student weights/dualkd_student.pth --out runs/roi
```

For full images, pass an oil-fill-port detector checkpoint to `--yolo`; use `--aligned` for ellipse-aligned crops. To generate dense teacher proxies and thin-ring pseudo-labels, provide the [official Depth Anything V2 repository](https://github.com/DepthAnything/Depth-Anything-V2) and its relative-depth ViT-L checkpoint:

```bash
python -m hed3d.run data/images --yolo private/oil_port_yolo.pt --aligned --student weights/dualkd_student.pth --dav2-repo third_party/Depth-Anything-V2 --dav2-weights private/depth_anything_v2_vitl.pth --out runs/images
```

The `--cloud` option screens teacher-derived thin-ring points with the student's scalar depth reference. It writes a local relative point set with pixel coordinates and scaled relative depth. The student itself outputs one ROI scalar. Third-party software and weights are governed by their respective upstream licenses.

## Train or evaluate with your data

Prepare train and validation CSV manifests with `image,Z_rel_cam,vehicle_id`, and keep the vehicle-level test split separate. Rows generated by the pseudo-label tool may carry confidence metadata. The training objective reads the scalar target and uses the original loss weights described in [the evidential formulation](docs/reliability.md). A separate pretrained dual-head checkpoint can supply frozen distillation targets:

```bash
python -m hed3d.train_student --root runs/images --train-csv private/train.csv --val-csv private/val.csv --kd-checkpoint private/frozen_teacher.pth --out runs/student --device cpu
```

Use `python -m hed3d.evaluate relative PREDICTIONS.csv` for per-ROI depth metrics on saved predictions and `python -m hed3d.evaluate metric CALIBRATION.csv TEST.csv` for independently calibrated physical distance. [Input formats and evaluation boundaries](docs/reliability.md) describe which data each command needs.

The [original public repository](https://github.com/SRH-opos/HED-3D) contains earlier research scripts. This package provides the organized entry points for the revised manuscript.
